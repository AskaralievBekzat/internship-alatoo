# UniClub

## Description

UniClub is a platform that helps students discover university clubs, apply for membership, and track application statuses.

The platform also includes an AI-powered recommendation system that suggests suitable clubs based on students' interests.

---

## Features

- University email authentication
- Club directory
- Club information pages
- Membership application system
- Application status tracking
- Club president dashboard
- AI-powered club recommendations
